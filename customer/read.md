Customer Registration Form - JavaScript Browser Lab
👨‍💻 Deskripsi Project
Project ini merupakan aplikasi form pendaftaran pelanggan (Customer Registration Form) yang dibuat menggunakan PHP, HTML, CSS, dan Vanilla JavaScript. Aplikasi ini bertujuan untuk mempelajari proses pengolahan data form, validasi input, serta interaksi pengguna melalui JavaScript tanpa menggunakan framework tambahan.

🎯 Tujuan Pembelajaran
Melalui project ini, saya mempelajari dan mempraktikkan:

Menyelesaikan file index.php, submit.php, dan success.php
Memahami konsep dasar Vanilla JavaScript
Membuat form pendaftaran menggunakan HTML, PHP, dan JavaScript
Membuat pop-up petunjuk (instructions) untuk membantu pengguna memahami cara pengisian form
Melakukan debugging error pada kode JavaScript
Menambahkan fitur input Nomor Telepon
Menambahkan validasi form untuk memastikan seluruh data wajib telah diisi
Menampilkan pesan peringatan apabila ada data yang belum diisi
Mengelola pengiriman data form menggunakan metode POST
🚀 Fitur Aplikasi
✅ Form Pendaftaran Customer
Form digunakan untuk menginput data pelanggan seperti:

Nama Lengkap
Email
Nomor Telepon
✅ Validasi Form
Sistem akan melakukan pengecekan otomatis terhadap:

Field yang masih kosong
Format email yang tidak valid
Nomor telepon yang belum diisi
✅ Pop-up Petunjuk
Pengguna dapat melihat petunjuk penggunaan form melalui tombol bantuan yang menampilkan pop-up informasi.

✅ Pesan Error Interaktif
Apabila terdapat data yang belum lengkap, sistem akan menampilkan pesan peringatan secara langsung tanpa perlu me-refresh halaman.

✅ Halaman Success
Setelah data berhasil dikirim, pengguna akan diarahkan ke halaman konfirmasi keberhasilan.
